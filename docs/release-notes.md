# Release Notes

## Version 2026.10.25-14 — Production release

### Highlights

- First production release of the game on Google Play.
- Arcade-inspired Christmas delivery gameplay: guide Santa's sleigh, drop gifts into chimneys, and build delivery combos.
- Animated winter scenery, crows, present-thieves, guardian-angel shields, candy-cane shots, arcade-style music, and sound effects.
- Local top-ten high scores and separate music and sound-effect controls.
- Keyboard, gamepad, and touch controls.
- No account, advertisements, analytics, or online leaderboard.
